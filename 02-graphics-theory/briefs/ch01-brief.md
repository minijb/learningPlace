### 1.2 向量：方向与长度的几何语言
- 向量 = 方向 + 长度，无绝对起点（GAMES101 L2 口径）；「位移不是位置」——点与向量的区分在此埋伏笔（1.6 的 w 分量正式收束）。
- 基本运算：加法（平行四边形/三角形法则；数值=分量相加，几何=位移叠加）、标量乘（拉伸/翻转方向）、减法 a−b = 「从 b 指向 a」。
- 归一化 â = a/|a|：「只谈方向」的标准姿势；单位向量是后续一切角度讨论的前提（cosθ = a·b 的几何式要求先单位化）。
- 默认列向量声明（GAMES101/OpenGL 惯例），行向量世界一句预警（1.7 正式展开约定之战）。
- 示例规划：说明性片段即可（向量加减/归一化的打印小程序，或纯文字+符号推演）；本节无完整可编译大示例的必要。
- 粗体结论候选：**向量是位移不是位置——它没有家，只有方向和长度。**
- 篇幅预算：约 80–100 行。
- 开场痛点建议：把「位置」和「位移」混着用——平移一个「方向」导致光照随物体移动而变；从「向量没有家」切入。

### 1.3 点乘：夹角、投影与光照的同一把尺（对位检验标准②前半）
- 定义两版并说明等价：分量式 a·b = axbx+ayby+azbz；几何式 |a||b|cosθ（等价性给直觉说明，不做严格证明）。
- 三大用途（每条配一小段数值说明或片段）：
  1. 夹角与方向关系：cosθ = a·b/(|a||b|)；正=同侧、零=垂直、负=背向（forward/backward 判定）。
  2. 投影与分解：a 在 b 上的投影 = (a·b̂)b̂；任何向量可分解为「平行+垂直」两分量（正交基直觉的种子，点到即止）。
  3. **Lambert 光照 N·L = cosθ**（图形学最重要的一个点乘：光照贡献=表面朝向与光线夹角的余弦；完整光照模型将在第 4 章展开）+ 背面剔除 N·V < 0（与 1.4 叉乘一起构成检验标准②的完整答案）。
- 示例规划：**完整可编译**——一组向量对，打印 cosθ、投影向量、Lambert 贡献系数、剔除判定（纯数值输出，无图形 API；文件头注释 `// ch01_dot_products.cpp —— ...（完整可编译）`）。
- 粗体结论候选：**点乘是「两个方向有多一致」的标尺：正=同侧、零=垂直、负=背向——光照与剔除问的都是这个问题。**
- 篇幅预算：约 120–150 行（重节）。
- 开场痛点建议：两个最常见现场——「背光面莫名发亮」（夹角没处理/方向没统一）与「该看见的面被剔掉了」（点积判错侧）；都是点乘读数问题。

### 1.4 叉乘：法线、定向与左右判定（对位检验标准②后半）
- 定义：分量式（行列式助记形式）+ 几何式 |a×b| = |a||b|sinθ；方向由右手定则给出（右手系约定下）。
- **叉乘方向依赖手性**：左手系下结论翻转（1.7 正式展开；跨 API 的 Z 朝向差异此处只立概念）。
- 三大用途：
  1. 三角形法线 N = normalize((B−A)×(C−A))——顶点顺序=朝向约定（绕序反了法线就反），这是「叉乘为何出现在背面剔除」的完整答案。
  2. 左右关系与内外判定：连续叉乘同号 ⇔ 点在三角形内（GAMES101 口径；第 3 章光栅化的覆盖判定正式上岗）。
  3. 构建局部坐标系：叉乘一次得到垂直方向，两次得到标准正交基（相机正交基的种子，lookAt 归第 2 章）。
- 自身性质（性质测试的对象）：a×b ⊥ a 且 ⊥ b、a×a = 0、反交换 a×b = −b×a。
- 示例规划：**完整可编译**——三角形三顶点 → 法线 → 与视线/光线的朝向判定打印；顺手演示「绕序翻转、法线反向」。
- 粗体结论候选：**点乘量「同不同向」，叉乘给「垂直于两者的那个方向」——光照用前者读数，法线靠后者出生。**
- 篇幅预算：约 120–150 行（重节）。
- 开场痛点建议：「三角形从背面看消失/从正面看消失」——绕序、法线、手性三件事拧在一起的事故现场；先拆出「法线怎么出生」。

### 1.5 矩阵 = 线性变换：乘法即复合（对位检验标准①主场）
- 线性变换两条件：F(a+b)=F(a)+F(b)、F(ca)=cF(a)；**矩阵是线性变换的账本——每一列 = 一个基向量去哪了**（3B1B 核心画面，也是手推一切变换矩阵的通用方法）。
- 【推导规划·显式】2D 旋转矩阵手推全过程：从「x̂ 旋转后到 (cosθ, sinθ)、ŷ 到 (−sinθ, cosθ)」出发拼出 [cosθ −sinθ; sinθ cosθ]；同法推缩放（对角矩阵）、剪切（单位矩阵改一格）。此推导即检验标准①「不查资料手推」的训练场，正文必须走完整推导而非给结论。
- 3D 旋转概念级：Rx/Ry/Rz 三张矩阵的形状一眼认得即可（「2D 旋转嵌进 3D + 单位轴不动」），完整解剖不展开。
- 乘法 = 复合：矩阵-向量乘法 = 「列的线性组合」几何解读；**顺序不可交换**（先旋转后平移 ≠ 先平移后旋转，配数值反例打印）。
- 正交矩阵：RᵀR = I ⇔ 列向量组标准正交；旋转矩阵正交 ⇒ 保长度、保角度、保点乘——**这是 1.10 性质测试 RᵀR=I 验的对象**。
- 示例规划：**完整可编译**——手推结果 vs 程序计算的对照打印（2D 旋转/缩放/复合、顺序不可交换反例）。
- 粗体结论候选：**读矩阵别读数字，读「基向量去哪了」；复合变换 = 矩阵连乘，次序即命运。**
- 篇幅预算：约 150–180 行（重节）。
- 开场痛点建议：「抄来的变换矩阵和教程长得不一样（像转置了）」与「先平移后旋转结果飞出屏幕」——约定与次序两颗雷；本节先炸次序这颗。

### 1.6 齐次坐标与仿射变换：平移为何要升维
- 【推导规划·显式】平移破坏线性：f(u) = u+a 时 f(0) = a ≠ 0，违反「线性变换保持原点」；3×3 矩阵无论怎么填都表达不了平移（CSE167 论证路线）。
- 升维解法：2D 点 =(x, y, 1)、2D 向量 =(x, y, 0)（CS184 口径）→ 平移进入矩阵最后一列；线性变换+平移 = 仿射变换；**平移只动点、不动向量**（方向平移不变——w 的第一个语义）。
- w 的第二个语义一句伏笔：w 还能当除数（透视除法），将在第 2 章变换链正式展开（NVIDIA Cg Tutorial「w 是除数」口径一句，不展开）。
- 仿射变换族清单：rotate/scale/shear/translate 及其复合；4×4 Mat4 布局（平移放哪一列）与 1.7 的约定绑定——本章选定列向量右乘。
- 示例规划：**完整可编译**——同一个平移矩阵分别作用于点 (x,y,z,1) 与向量 (x,y,z,0)，打印「点被平移、向量纹丝不动」。
- 粗体结论候选：**w=1 的是点（有位置），w=0 的是向量（只有方向）——升维不是技巧，是让平移也进矩阵的代价与红利。**
- 篇幅预算：约 100–130 行。
- 开场痛点建议：「为什么 3D 平移非得搞个 4×4？多出来那行 0 0 0 1 是什么巫术」——从「3×3 装不下平移」的代数困境切入。

### 1.7 约定之战：行/列向量、主序与左右手系（易混淆重灾区）
- 乘法方向两派：列向量右乘 Mv（数学教材/OpenGL/GLM，变换从右往左读）vs 行向量左乘 vM（DirectX 传统，从左往右读）；两套写法的矩阵互为转置。
- **存储主序与乘法方向是两个独立概念**：行主序/列主序是内存摆放顺序，vM/Mv 是数学约定——存在「列向量约定 + 行主序存储」的组合（Pavel Šmejkal 文章专门澄清）；GLM（列主序+列向量）vs DirectXMath（行主序+行向量）对照一句。
- 左右手系：右手系（OpenGL/GLM/GAMES101 默认）vs 左手系（DirectX 传统）；手性影响叉乘方向、Z 轴朝向与深度范围——跨 API 移植的坑点在第 3/6 节正式结算，本章只立「手性是约定的一部分」的概念。
- 本章选定声明（粗体结论候选）：**约定没有对错，全程一致才是命——读别人代码先看它是 vM 还是 Mv、Z 朝里还是朝外。**
- 示例规划：说明性对照表 + 文字为主（两套约定同一段变换代码的并排示意片段）；不必完整可编译。
- 篇幅预算：约 90–120 行。

### 1.8 微积分核心：梯度求法线，积分算总和
- 导数 = 瞬时变化率 / 切线斜率（一元直觉起步）；多元升级到偏导与梯度 ∇h = (∂h/∂x, ∂h/∂y)。
- 【推导规划·显式】高度场求法线：h(x,y) 的法线 ∝ normalize(−∂h/∂x, −∂h/∂y, 1)——为什么带负号（梯度指上坡、法线是它的「垂直转身」）、为什么 z 分量是 1（坡度越陡法线越水平）。
- 数值求导一句：有限差分 (h(x+ε)−h(x−ε))/2ε 是解析梯度的数值替身（深入专题的主演员）；法线贴图 = 逐像素存梯度信息的概念一句（切线空间将在第 4 章展开）。
- 定积分 = 连续求和：黎曼和直觉（矩形面积取极限）；图形学消费点——渲染方程就是一个积分（将在第 6 章展开）、一切「累加贡献」的计算都是它的离散亲戚。
- 基础训练对齐：d/dx x²、∫₀¹ x dx 级别的手算题在自测题①与任务 2 落地（检验标准①后半「能做基础求导/积分题」）。
- 示例规划：说明性片段（梯度公式代入一个具体 h(x,y) 手算一遍）；完整实验留给深入专题。
- 粗体结论候选：**梯度指向「上坡最快」的方向，法线是它的垂直转身；积分是把无穷多份小贡献加起来。**
- 篇幅预算：约 110–140 行。
- 开场痛点建议：「地形光照看起来不对但说不出哪不对」——法线错了；而求法线的正路是微积分不是拍脑袋。

### 1.9 概率直觉：期望、方差与大数定律（概念级，蒙特卡洛铺路）
- 三件套各一句：期望 = 长期平均、方差 = 离散程度、大数定律 = 样本均值收敛到期望。
- 图形学消费点一个就够：路径追踪的噪点 = 随机采样的方差，样本数↑ ⇒ 噪点↓（大数定律的视觉版本）；「为什么多采样会变清晰」的完整机制将在第 7 章展开。
- 最小示例（完整可编译）：均匀随机采样估算 π（单位圆/单位正方形面积比）——蒙特卡洛最小现场：随样本数 10²→10⁶ 打印估计值收敛过程（输出标注「示例输出（示意）」；随机数用 <random> 固定种子保证可复现）。
- 顺带一句「积分=期望」的桥梁（第 7 章重要性采样的伏笔），不展开。
- 粗体结论候选：**噪点是方差的脸，样本数是它的解药——大数定律是路径追踪的地基。**
- 篇幅预算：约 80–110 行。
- 开场痛点建议：「渲染出来的图全是噪点，等一会又变干净了」——这不是 bug，是随机采样的方差在收敛；先把直觉立住，机制留给第 7 章。

### 1.10 数学库工程：Vec2/3/4 与 Mat4 落地（实践任务主场，对位检验标准③）
- 设计决策逐条（每条=一个后向引用的落点）：
  - 纯值类型，全部 rule of zero（兑现 01-cpp 阶段 1「为第 2 节数学库标注零/三/五法则」挂账——答案是全零）。
  - 运算符按值返回、零堆分配、成员 constexpr 友好（ch06 性能意识一句对齐）。
  - 默认 float 具体版；模板化 float/double 同套测试为可选进阶（ch03「先具体后泛化」）。
  - **每函数一句几何意义注释**（Stages 实践任务原文要求——「normalize 是把长度拧到 1、方向不变」级别的注释）。
- API 骨架：Vec2/3/4（+ − ×标量、dot、cross(Vec3)、length、normalize）；Mat4（identity、mat×mat、rotateX/Y/Z、scale、translate、transform 点/向量）——lookAt/ortho/perspective/viewport 留第 2 章（P3·M0 后半，阶段 2 实践任务原文「在阶段 1 数学库上实现」）。
- 性质测试清单（检验标准③主场）：RᵀR=I（旋转矩阵正交性）、a·(a×b)≈0（叉乘垂直性）、|a×b|=|a||b|sinθ、旋转保长度、正交变换保点乘；**浮点比较一律容差而非 ==**（容差量级给建议值并说明为什么）。
- 测试载体：单文件 assert 式自测起步（零工程依赖）；接 CTest 为可选进阶（ch04 资产复用，不强制）。
- 示例规划：**完整可编译**——Vec3 + 核心运算的骨架级实现（其余类型同构，正文给一两类完整、其余留任务 1）；性质测试的 assert 式写法示范。
- 粗体结论候选：**数学库不是抄公式，是把几何直觉钉进 API——每个函数名都应该能说出一句几何意义。**
- 篇幅预算：约 150–180 行（重节）。
- 开场痛点建议：「面试让手写旋转矩阵，背过但忘了怎么推」以及「库函数结果和手算对不上、分不清谁错」——性质测试就是裁判。

## 自由小节（深入专题）：一个高度场的法线解剖——梯度、叉乘与数值验证的三方对账（150–260 行）
- 选题理由：同时消费 1.3（dot 对账）、1.4（cross 求法线）、1.8（解析梯度/数值求导）——全章线代与微积分的合流处；且高度场法线正是 P3 软件光栅器光照输入的预演（观念级一句）。
- 三条路取同一批法线：
  1. 解析梯度路线：h(x,y) 有闭式偏导时直接代入 normalize(−∂h/∂x, −∂h/∂y, 1)。
  2. 有限差分路线：数值求导近似梯度（ε 的选择与精度讨论）。
  3. 离散几何路线：高度场网格化成三角形后用 (B−A)×(C−A) 求面法线。
- 完整可编译实验：合成高度场（如 h(x,y) = sin(x)·cos(y) 类），规则网格采样，三路法线逐点对账——打印点积/夹角差；讨论「三者何时一致、何时分歧」：有限差分误差随 ε 与网格密度的行为（只给量级与方向性讨论，输出标注「示例输出（示意）」，精度数字以本机实测为准口径）。
- 收束段：法线是光照的输入（1.3 的 N 在此有了出身）；数值意识的雏形（误差量级、容差选择）——第 4 章着色的地基在此埋下。
- 工程注记：这正是数学库 normalize/cross/dot 的第一场实战（任务 1 完成后可回头用库重写本专题）。

## 自测题（8 题，第 1–3 题对位检验标准；题型混合：手推/口述/工程/概念/辨析/场景/计算）
1. 手推题（对位①）：从「基向量去哪」出发手推 2D 旋转矩阵一般式，并写出 R(90°)；再手推 uniform scale=2 的矩阵；最后两道微积分手算：d/dx x³、∫₀¹ 2x dx。
2. 口述题（对位②）：点乘为何出现在 Lambert 光照（cosθ 从哪来、为何「正对光最亮」）；叉乘为何出现在背面剔除（法线怎么来的、顶点绕序与朝向什么关系）。
3. 工程题（对位③）：列出数学库应做的性质测试并说明每条在验什么性质；浮点容差怎么定、为什么不能用 ==。
4. 概念题：w=1 与 w=0 的语义差别；平移矩阵分别作用于点和向量时发生什么。
5. 辨析题：行/列主序与行/列向量约定是不是同一件事？举一个「列向量约定 + 行主序存储」的现实组合并说明为什么它成立。
6. 场景题：先旋转后平移 vs 先平移后旋转，画图说明结果差异；列向量右乘约定下复合矩阵 M1M2v 该按什么顺序读。
7. 计算题：给定 h(x,y)，写出梯度与法线公式并解释负号；有限差分的 ε 取太大/太小时各出什么问题。

## 常见误区（8 条，症状/病根/纠偏三段式）
1. 只看视频不写作业（对位 Stages 原文：3B1B/GAMES101「看懂了」≠「会推了」，价值在动笔与作业）。
2. 第一遍就用 GLM 代替手写数学库（对位 Stages 原文：错过建立几何直觉的关键机会；工程化阶段再换）。
3. 前置数学贪多求全、迟迟不进图形学正文（对位 Stages 原文：钻进特征值/行列式深水区；只学消费子集，学完即走）。
4. 全程跳过推导只记结论（对位 Stages 原文：公式背了不推，理论根基空，违背本节定位）。
5. 把行/列主序与乘法方向混为一谈（存储是内存问题、约定是数学问题，两个独立轴；移植时「矩阵看起来被转置了」的真因）。
6. 叉乘方向不看手性（在左手系沿用右手定则结论——法线朝向翻转、剔除判定反向）。
7. 性质测试用 == 比较浮点（误差累积下永远过不了测试；应按量级设容差）。
8. 点与向量乱升 w（把方向也平移了，或把位置当「平移不变」处理——1.6 语义混乱的工程面）。
